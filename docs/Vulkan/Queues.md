# Queues

In Vulkan, [command buffers](./Command_Buffers.md) are sent asynchronously through Vulkan queues.

## Queue Families

A queue family represents a set of queues that support a specific set of operations. The support for these queue families can also be validated when selecting a [physical device](./The_Physical_Device.md).
