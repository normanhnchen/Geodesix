# The Vulkan Instance

The Vulkan instance connects the application to the Vulkan API. Specifically, it bridges this gap through initializing any Vulkan drivers, API extensions, application specifications, debug (i.e. [validation layers](./Validation_Layers.md)) and retrieving data about the [physical device](./The_Physical_Device.md).
