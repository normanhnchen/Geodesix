# Image Views

A Vulkan image view describes how the image data should be accessed and used by the [graphics pipeline](./Pipelines.md) and [shaders](./Shaders.md). This includes images such as in the [swap chain](./The_Swap_Chain.md), textures, or framebuffers. On average, a graphics card can support up to 16 image views.
