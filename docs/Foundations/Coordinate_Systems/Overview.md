# Overview

## 3D Cartesian Coordinates 

3D Cartesian coordinates are defined with three real numbers $(x, y, z)$ that define the position of a point in three-dimensional space. We define the mathematical convention of $z$ being the upwards direction.

## UV Coordinates

UV coordinates define a 2D coordinate system used to map a pair of 2D real numbers $(u, v)$ in range $[0, 1]^2$ onto a 3D surface.

## Spherical Coordinates

Spherical coordinates are a 3D coordinate system that defines the exact position of a point using a radius (distance from the origin $(0, 0, 0)$) and two angles: $(r, \theta, \phi)$. Using mathematical conventions with the $z$ direction is up, $\theta$ is defined as the horizontal rotation on the $xy$-plane starting from the positive x-axis (the *azimuthal* angle), and $\phi$ is defined as the angle swinging downwards from the positive $z$-axis (the *polar* angle).

## Schwarzcshild Coordinates

Schwarzschild coordinates are a set of space-time coordinates $(t, r, \theta, \phi)$ used to describe the gravitational field around a static, spherically symmetric, uncharged, and non-rotating mass. $t$ is the time coordinate, $r$ is the radial coordinate (the radius a sphere would have in flat space to posses the exact same surface area), and $(\theta, \phi)$ represent standard polar and azimuthal angles in spherical space.
